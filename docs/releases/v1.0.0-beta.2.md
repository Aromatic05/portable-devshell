# portable-devshell v1.0.0-beta.2

This historical Beta release follows beta.1. It is a prerelease, not an RC
or a guarantee of backward-compatible behavior.

## Changes since beta.1

- **Goal and Agent Memory**: the previous separate Todo workflow was
  consolidated into Goal, with auto-bound Agent Memory, stronger explicit
  memory initialization, and recovery of durable activity and progress.
- **Wait and recovery**: more reliable tmux transcript observations, Wait
  redelivery, Goal continuation, and instance-independent model re-entry
  across temporary disconnects or a Control restart.
- **Worker file snapshots**: shell-read observations now support file-edit
  snapshot coverage and bounded, model-visible output instead of crediting
  unobserved file regions.
- **Transport and interface**: more restrictive peer promotion and fallback
  after disconnect; clearer Reverse enrollment and approval navigation,
  and improved workspace approval queues and paginated audit history.
- **Installation**: worker and application activation can be staged before
  shutting down the existing Control.

## Compatibility and verification

Compatibility depends on negotiated Control, Worker, and Frame protocols,
Extension API, and domain persistent schemas rather than product version
alone. A running instance or OAuth session may need to reconnect after an
upgrade. Side-effecting ToolCalls must not be replayed merely because their
transport acknowledgement was lost.

This note describes the tagged beta.2 change interval, not the current
beta.3 development state or any later test result. Check
[the current acceptance gates](../development/acceptance.md) when preparing
a newer release.
